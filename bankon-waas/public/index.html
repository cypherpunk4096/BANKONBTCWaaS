Native SegWit bc1q…
Lowest everyday feesNear-universal supportRecommended
  • The best default for most people. Its transactions are the smallest of the broadly-supported types, so it pays the lowest fees when you spend.
  • Addresses start with bc1q — all-lowercase bech32 format that catches typos before you send.
  • Accepted by virtually every modern wallet and exchange.
  • Derivation m/84'/0'/0' (BIP84).
Taproot bc1p…
Best privacyEfficient multisigNewest (2021)
  • The newest address type. A simple payment and a complex multisig/script look identical on-chain, so Taproot leaks the least information about how your wallet is set up.
  • Cheapest for advanced spends (multisig, smart-contract scripts); about the same as Native SegWit for ordinary sends.
  • Addresses start with bc1p — bech32m format. Derivation m/86'/0'/0' (BIP86).
  • Heads-up A few older exchanges still can't send to bc1p addresses yet.
Legacy 1…
Maximum compatibilityHighest fees
  • The original Bitcoin address format — understood by every wallet and service ever made.
  • Its transactions are the largest, so it costs the most in fees to spend. There's no privacy or fee benefit over the newer types.
  • Addresses start with 1 — Base58 format. Derivation m/44'/0'/0' (BIP44).
  • Only choose this if you must interoperate with very old software.

🔬 Post-quantum option (Falcon) — experimental

Bitcoin signatures stay secp256k1 (Tier-C — consensus-frozen, classical). This POC mints a Falcon (FN-DSA) post-quantum identity key for the quantum-native path (CP2048-QR Tier-Q; the scheme Algorand went quantum-native with) — crypto-agile, alongside your BTC key, never replacing it. The secret key is never sent to the server.

    ❓ FAQ — tap a question; each answer links to the full guide

    

      Is BANKON custodial? Where do my keys live?
      
No. Your keys are minted here in your browser and never reach the server —
        BANKON even rejects any request containing a secret. The node only holds a watch-only
        descriptor and builds unsigned transactions; you sign locally.

      New here — what is BANKON BTC WaaS?
      
A non-custodial Wallet-as-a-Service that attaches to your own Bitcoin Core node —
        it watches and drafts, it never holds your keys.

      Which wallet type should I choose?
      
Native SegWit (bc1q…) is the default and cheapest; Taproot (bc1p…) is newest;
        Legacy (1…) is maximally compatible. Multisig is supported too.
        Wallet types & the create→sign→send loop ↗

    


    

      Do I need Bitcoin Core running?
      
To register a wallet, see balances, build a send, or broadcast — yes.
        To generate or sign a wallet — no; those are client-side and work air-gapped.
        Standalone & air-gapped WaaS ↗

    


    

      Can I sign offline / air-gapped?
      
Yes. The offline signer
        makes zero network calls (the crypto libraries are vendored locally). Recommended for real
        funds: an online watch-only host plus an offline signer.
        Air-gap guide ↗

    


    

      How do I receive a payment (with an amount)?
      
BANKON builds a shareable bitcoin: payment request (amount, label,
        message) — something Bitcoin Core doesn't provide.
