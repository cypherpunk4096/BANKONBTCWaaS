================================================================================
  BANKONME — ARCHIVE MAP
  The decades-old self-custody vision behind bankon-vault.
  Org: https://github.com/bankonme
  Mission (verbatim): "privacy, integrity and security for your personal
  banking information."  →  be your own bank, keys offline.
================================================================================

This is a curated map of the bankonme software archive (the org holds ~452 repos,
overwhelmingly forks; the significant tools are indexed below with URL + a brief
description). bankonme PRECEDES bankonOS and is the founding lineage of BANKON.
No secrets or private material from any legacy artifact are included here.

--------------------------------------------------------------------------------
  COLD STORAGE & OFFLINE KEY GENERATION  (the core of the plan)
--------------------------------------------------------------------------------
cold-storage          https://github.com/bankonme/cold-storage
                      Scripts to safely store bitcoin offline. [Python]
                      → the literal "keys offline" spec bankon-vault fulfils.
bitaddress.org        https://github.com/bankonme/bitaddress.org
                      Client-side (in-browser) Bitcoin wallet / paper-wallet
                      generator — no server ever sees the key. [JavaScript]
monero-wallet-generator  https://github.com/bankonme/monero-wallet-generator
                      Self-contained offline JavaScript Monero wallet generator. [HTML]
BitcoinArmory         https://github.com/bankonme/BitcoinArmory
                      Python/C++ cold-storage & multisig Bitcoin wallet. [C++]
keyhunter             https://github.com/bankonme/keyhunter
                      Recover lost bitcoin private keys from dead hard drives. [Python]
trezor-emu            https://github.com/bankonme/trezor-emu
                      Python TREZOR-compatible hardware-wallet emulator. [Python]

--------------------------------------------------------------------------------
  DISK / PARTITION ENCRYPTION  (the "frozen storage" heritage)
--------------------------------------------------------------------------------
LUKS                  https://github.com/bankonme/LUKS
                      Secure encrypted disk partition. [Shell]
                      → heir line to bankon-vault's removable-media (LUKS) cold path.
zuluCrypt             https://github.com/bankonme/zuluCrypt
                      Front end to cryptsetup / tcplay for encrypted block devices. [C]
