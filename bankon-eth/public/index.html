BANKON.ETH EVM Wallet as a Service · non-custodial · twin of BANKON BTC/ALGO

Keys (BIP39 phrase → secp256k1 → EVM address) are generated here, in your browser (ethers.js). BANKON never receives them — only your public address (watch-only) and already-signed raw transactions reach the node. EVM-generic: works on Ethereum, L2s and testnets (chain detected via eth_chainId).

checking EVM node…

1 · Create a wallet (client-side keygen)
2 · Track an address (watch-only)
3 · Send (build → sign locally → broadcast)

Port :4448 (twin of BANKON BTC :8088 · ALGO :4444). Non-custodial invariant identical — the server rejects any request containing a phrase/private key.
