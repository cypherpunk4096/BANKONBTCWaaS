bankonmeOS

Posted January 12, 2017 · by developer

Welcome to the bankonmeOS operating system project WebQuarters. bankonmeOS Developer edition install script to be released soon. Work with Ubuntu 16.04LTS Mate continues. Debian 6, 7 and 8 are still being explored. Install lessons have emerged from the team at Kali Linux and further advances in privacy from the team at TAILS. Recent advancements in virtualization are very exciting.

To date testing of the released bash-script installer has been isolated to Ubuntu 16.04LTS.

The bankonmeOS.Ubuntu16.04LTSmate install script is codenamed “Aristotle” and will be found in the github.com/bankonmeOS/aristotle repository.

the bash builds carried philosopher codenames — Aristotle, Babbage, Hume …

2026 update. The plan held: be your own bank, keys offline. bankonmeOS now favours Alpine and OpenBSD (with Debian compatibility). The self-custody idea grew into BANKON — a non-custodial Bitcoin Wallet-as-a-Service that attaches to your own node — and the definitive bankon-vault (encrypted keys, signature-gated, sign-don't-export, air-gap “frozen” storage in ICE). All under the cypherpunk2048 standard.

The mission has not changed since day one: privacy, integrity and security for your personal banking information.
